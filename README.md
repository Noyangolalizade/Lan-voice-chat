برای استفاده از برنامه دو روش وجود داره ولی برای اجرای هر دو روش باید یک کار رو در اول انجام بدید
اول cmd یا همون command prompt ویندوز رو باز کنید.داخل کامند پرامپت تایپ کنید cd با یک فاصله در جلوش سپس فایل برنامه رو که اکسترکت کردید(zip نباید باشه باید فایل رو اکسترکت کنید) بکشیدش و رهاش کنید در کامند پرامپت
در این حالت باید با یه همچین صفحه ای مواجه بشید

<img width="1447" height="696" alt="image" src="https://github.com/user-attachments/assets/33b92354-68b2-4e7f-b5c1-151b8ccf2058" />
حواستون باشه که کامند پراپمت رو به صورت عادی باز کنید و ران از ادمینیتور(اجرا به عنوان مدیر) نزنید
سپس اینتر بزنید و این کامند رو بنویسید : npm start



<img width="1447" height="695" alt="image" src="https://github.com/user-attachments/assets/bc6a2c17-a1e0-4227-8512-ca4b5a4efd2a" />
حالا باید صفحه بالا رو ببینید اگه ارور داد فقط کافیه بزنید npm install و بعدش بزنید npm start و درست میشه.
حالا به دلیل مشکلات فارسی در کامند پرامپت اونشکلی نوشته شده اون پیام. در اصل نوشته که سرور روی پورت 3000 فعال شد.
توجه کنید که باید قبل همه اینها پکت رفت خودتون رو روشن کنید.کسانی که میخوان با شما توی وویس چت باشن هم باید پکت رفت روشن کنن و برن به قسمت lan و ایپی بگیرن. ایپی اونها مهم نیست مهم ترین بخش ایپی هاست هست.خود شما برای هاست کردن فقط کافیه بعد از استارت کردن سرور برید به مرورگر کروم و این نشانی رو سرچ کنید
http://localhost:3000/

<img width="1920" height="1080" alt="image" src="https://github.com/user-attachments/assets/429a3787-d814-4edd-886e-a35a46fc7bfd" />
اگه راه رو درست رفته باشید با این صفحه داخل کروم مواجه میشید اسم خودتون برای ورود و اسم کانال رو وارد کنید اگه میخواید خصوصی باشه رمز بزنید و روی ورود کلیک کنید.

<img width="1920" height="1080" alt="image" src="https://github.com/user-attachments/assets/113166ef-2385-4fea-b27f-e6f09035e1d8" />
این هم از وویس چت شما بقیه اعضا برای ورود به کانال شما فقط کافیه پکت رفت روشن داشته باشن و توی مرورگرشون ایپی شما رو به همراه پورت سرچ کنن مثلا اگه ایپیتون هست 10.240.50.80 اگر کسی بخواد وارد بشه باید سرچ کنه
10.240.50.80:3000
بهتره که توی خود کروم سرچ کنید نه سایت گوگل.
